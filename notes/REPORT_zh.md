## 1. 选题：怎么找到一个"真能做出东西"的开放问题

- 先扫了一遍 Erdős 问题的"计算前沿"清单（Erdős Frontier Atlas 数据集、
  erdosproblems.com、OEIS 的 hard 序列），筛出"有限对象 + 秒级可验证"的候选。
- 对每个候选核对**一手来源**（OEIS 当前条目、arXiv 最新版本、作者仓库），
  而不是相信二手综述：结果发现三个候选已经"被抢跑"（见 §5）。
- 最终锁定"公开纪录只差一点、且可用构造搜索推进"的题目：**Erdős #86 的 Q₉ 情形**。
  它是有限问题：Q₉ 有 512 个顶点、2304 条边、4608 个正方形面；验证一个候选边集
  只需枚举 4608 个面，纯整数、微秒级。

## 2. 方法：为什么"全受挫自旋"一定给出无 C₄ 子图

在 Q₉ 上取耦合

    J(x, d) = (−1)^(x 的低 d 位的 popcount 数)，   d = 0,…,8。

可以验证（并在 Lean 里机械检查）：**每个正方形面的四条边上的耦合乘积都是 −1**。
于是对任意自旋组态 s : {0,1}⁹ → {±1}，取"满足边"

    E(s) = { xy : s_x·s_y = J(x,y) }

若某个正方形四条边全在 E(s) 中，把四个等式相乘：左边每个顶点出现两次，乘积为 1；
右边等于四条耦合之积 = −1，矛盾。故 E(s) 自动无 C₄。这是 Derrida–Pomeau–
Toulouse–Vannimenus (1979) 与 Marinari–Parisi–Ritort (1995) 在统计物理里用过的
"odd-square / fully frustrated" 构造；我们把它用在 n = 9。

搜索：`spinmax.c` 对 512 个自旋做多起点模拟退火，目标 = 正边数。
18 次独立运行（每次 ~5×10⁸ 次单自旋翻转）落在 1526–1532，**最高 1532，且两次独立命中**。
另外 18 次以 1532 为种子的边集 tabu 搜索（每次 5.5×10⁶ 步）从未超过 1532，
说明 1532 至少是一个强局部最优。

## 3. 验证（三层独立检查）

1. 循环枚举验证器（Lead）：枚举全部 4608 个正方形面，0 个完整出现。
2. 邻域判据验证器（Lead）：C₄-free ⟺ 任意顶点对的共同邻居 ≤ 1；
   9216 个 Hamming 距离 2 的顶点对全部满足。
3. 红队独立实现（teammate `q6-hypergraph`，与发现者不同代码）：PASS；
   负向对照（人为塞入一个完整 C₄、或复制一条边）均被正确拒绝 —— 验证器非空转。

产出的两个 1532 边解相差 1016 条边，说明 1532 不是单点偶然。

## 4. 同场加映：三条主攻线的严格负结果

1. **ex(Q₇, C₄) ≥ 305**（当前 [304, 308]；304 已被作者本人声明非新颖）：
   - 8 个独立的 304 边解（自旋退火，全部平台在 304；Q₆ 控制实验命中精确值 132）；
   - 对全部 8 个解穷举 **2-for-1 / 3-for-2 / 4-for-3** 交换：全部无 305 可达
     （4-for-3 检查了 4,636,304 个 kept-triple）；
   - 大邻域搜索（LNS + CP-SAT，37,000+ 个随机顶点邻域）与 12 进程 tabu 均未超过 304。
   - 结论：304 在这些邻域内是刚性的；305 仍开放（我们没拿到）。
2. **A276661 a(11) < 594**（Erdős 子集和互异问题的有限项；[462,594]）：
   - 穷举 1-opt / 2-opt（W 空间、|Δ|≤100，2.2×10⁶ 个候选）、模拟退火、CP-SAT（300 s）
     全部无 <594 的 11 元集；
   - 发现"只差一个关系"的 593 候选：{285,432,509,549,569,580,586,589,591,592,593}，
     违反 285+589+592+593 = 432+509+549+569 —— 说明 594 是一个很深的局部最优；
   - 顺带确认 a(12) ≤ 1157、a(13) ≤ 2249 也是 1-opt/2-opt/3-opt 局部最优。
3. **q(6)（Erdős–Lovász）**：审计发现 2026 年已有未评审 Zenodo 预印本声称 g(6)=17，
   因此 17 边构造只是复现而非纪录，主动放弃该目标（这是本轮最有价值的一次"止损"）。

## 7. 诚实的局限

- **只是下界**：1532 ≤ ex(Q₉,C₄)；既没有证明 1532 最优，也没有改进任何渐近界。
- **新颖性范围**：比对的是公开可检索来源（OEIS、arXiv、Erdős Problem a Day、
  相关仓库），截至 2026-10-17；无法排除未索引的私人/旧统计物理文献已有 n=9 的值。
- 未使用分布式规模算力：全部实验约 20 核 × 数小时。
- Lean 文件的可信度依赖 `native_decide` 的编译执行（Lean 标准做法），
  且需要相应工具链才能复跑；同时提供了纯 Python 的独立验证器以便任何环境复核。
